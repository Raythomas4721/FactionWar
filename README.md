# 四族戰紀（FactionWar）

六個種族中每局四族參戰：獸人、精靈、矮人、人類、💀死靈族、🐜蟲族。

獸人、精靈、矮人、人類四個陣營的小人自動發展、打造、建設、互相征戰的模擬遊戲。
線上試玩：https://raythomas4721.github.io/FactionWar/

你可以當旁觀的神，也可以出手干預、改寫世界法則，或接管任何一個陣營。設計文件見 [docs/DESIGN.md](docs/DESIGN.md)。

## 玩法

- **上帝之手**：消耗神力施放 ⚡天雷、☣瘟疫、✨祝福、💰恩賜、🛡援軍、🕊神諭和平、🔥挑撥離間、🌲造林、⛏礦脈（快捷鍵 1–9，右鍵或 Esc 取消）
- **世界法則**：休戰時間、對局時限、戰鬥傷害、採集與研究速度、疫病強度、糧食消耗、策反成功率、發明頻率、參戰種族、中立巢穴、結盟共治勝利、資源蘊藏、開局科技、各種族天賦倍率、神力無限；設定會記在瀏覽器裡
- **由我指揮**：勾選陣營卡片上的「由我指揮」，就能決定該陣營進攻誰或防守、派外交官求和或結盟、宣戰，並下令訓練、建造（經濟仍由 AI 打理）
- **🏆 造物主的試煉**：六個固定局面的關卡（瘟疫之神、英雄之路、屠龍者、死者的黎明、弱者的逆襲、和平使者），限制可用神力、有成功失敗條件；失敗會給提示，可以用同樣局面再試，通過會記錄最佳時間
- **🌍 隨機事件**：每 4～6 分鐘一次——豐收年、寒冬、瘟疫季節、流星雨、獸潮、野火、神啟（世界法則可關閉）
- **附身英雄**：在英雄卡片按「👁 附身」親自操控，點地圖移動、點敵人攻擊、Q 放技能，Esc 解除
  - 鏡頭自動跟隨並放大（＋／－ 調整，可切回全景）
  - 🚩 跟隨我（F）：附近最多 10 名戰士組成小隊，跟著英雄打同一個目標
  - 傷害數字、暴擊大字、連斬（雙殺 → 三連斬 → 五連斬 → 殺神降臨）、受重擊時畫面震動
- **戰報分析**：戰局結束時列出各陣營的敗因與下次的建議（疫病、飢荒、策反、戰損、科技、巢穴、英雄）
- 空白鍵暫停，點擊小人或建築看詳細資料；手機上地圖可左右滑動

## 執行

```bash
npm install
npm run dev        # 開啟遊戲（網址會顯示在終端機）
npm test           # 單元測試
npm run balance    # 無畫面跑 100 場，統計各族勝率（可加參數：npm run balance -- 60 1）
```

## 已完成（M1 ～ M4）

- 四族各自的屬性（力量／敏捷／智慧／體質／魅力），個體在種族基礎值上隨機浮動
- 自動戰鬥：命中看敏捷、傷害看力量（近戰）或敏捷（遠程）、減傷看體質與護甲、士氣看魅力
- 經濟：採集木材／石材／鐵礦／漿果，農田、房屋、人口上限
- 科技：非戰鬥人員的智慧累積研究點數，書院加速；科技解鎖建築與裝備
- 打造：鐵匠智慧決定裝備品質（粗糙 → 大師之作），有種族專精與種族專屬武器
- 陣營 AI 透過指令佇列下達「訓練／建造／打造／進攻」（未來玩家指揮模式共用同一入口）
- 飢餓：每個人口都要吃糧（獸人食量大、精靈食量小），糧倉見底會挨餓、掉士氣、最後餓死
- 疾病：體質越高越不容易生病，矮人幾乎不生病；病人工作減半、會傳染給身邊的人（不分敵我）；醫館加速康復
- 外交：陣營之間有交戰／和平／同盟三種狀態與關係值；外交官出使求和、結盟（途中享有外交豁免），成功率看魅力、智慧、關係、共同敵人與實力差距；兵強馬壯時可能背盟
- 策反：挨餓、生病、士氣低落、節節敗退會讓忠誠度下降；外交官潛入說服敵人倒戈（帶著裝備投奔），失敗可能被識破處決。人類魅力最高，最會策反、最難被策反
- 兵種：步兵、長矛兵（剋騎兵）＋種族專屬：人類騎士／獸人狼騎兵（衝鋒）、矮人地道工兵（地底潛行、拆建築）、精靈林地伏兵（森林隱身、暗箭）
- 發明：鐵匠智慧越高，越常發明以自己命名的裝備藍圖（威力 ×1.1～1.5，附淬毒／烈焰／破甲／輕羽／堅固／祝聖等特效），只有自家能打造；精靈發明最多、獸人幾乎不會
- 建築設計：建造者的平均智慧決定建築品質，影響耐久與效果（農田產量、箭塔傷害、書院研究、醫館醫療）
- 新種族：💀死靈族（招魂讓戰死的活人化為骷髏兵；不吃不病不怕，怕火與聖光）、🐜蟲族（便宜、數量多、壽命短，殺敵吞噬換研究；擠在一起易染疫）
- 中立巢穴：四個象限的巨狼／石像鬼／古樹守衛與中央的遠古巨龍，守護遠古礦脈與寶藏（🏆秘術、⚔神器、📜上古圖紙）；最後一擊的陣營奪寶
- 英雄：戰士擊殺 4 人晉升英雄（每族最多 2 名），依種族與屬性走五種流派——⚔暴擊、☠毒傷、✦召喚、🔥狂戰、🛡守護；升級時二選一天賦，流派之間有 Combo（守護光環讓隊友暴擊、暴擊打中毒敵人觸發毒爆）；戰死的英雄留名英雄榜
- 勝利條件：統一大陸、全員結盟維持 5 分鐘（結盟共治）、或時間到比分數
- 同一個種子可重播同一場戰局

## 程式結構

- `src/sim/` 純 TypeScript 模擬核心，不依賴畫面
  - `systems/` 移動（A*）、戰鬥、經濟、建造、打造、換裝
  - `ai/utility.ts` 個體決策（Utility AI 打分）；`ai/faction.ts` 陣營策略
- `src/render/` Canvas 繪圖；`src/ui/` React 面板
- `tools/balance.ts` 平衡模擬器
